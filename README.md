# uikit-planing-q4-2026

Страница плана UI Kit на Q4 2026. Вёрстка и расчёты взяты из `live-plan-board`. Задачи можно перетаскивать между итерациями, но в Jira ничего не пишется: переносы хранятся в `localStorage` браузера.

## Данные

- `data/snapshot.json`: снимок задач. Его извлекают из страницы `live-plan-board`, сохранённой в браузере, или выгружают с этой страницы вместе с переносами.
- `data/capacity.json`: копия `live-plan-board/capacity/Q4_2026.json`.

Обновить снимок:

```sh
node scripts/extract-from-html.mjs "~/Desktop/UIKIT · Планирование.html" > data/snapshot.json
```

## Локальные переносы

- Перетащите строку за ⠿ в итерацию, на плитку загрузки или в группу «Без срока». Также можно нажать на ⠿ или клавишу M на строке и выбрать итерацию в форме.
- Срок ставится на конец итерации, как в `live-plan-board`. Перенос внутри той же итерации ничего не меняет, а возврат в исходную итерацию отменяет правку.
- Изменения хранятся в `localStorage` под ключом `uikit-plan-overrides-Q4_2026` и видны только в этом браузере. Их список с кнопками «Отменить» показан внизу страницы.
- «Скачать snapshot.json» и «Копировать JSON» выгружают полный снимок с уже применёнными переносами. Им нужно заменить `data/snapshot.json` в репозитории и запушить: после сборки правки увидят все. После этого локальные изменения можно сбросить.
- Повторное извлечение из сохранённой страницы `live-plan-board` перезапишет снимок вместе с переносами.

## Сборка

```sh
node build.mjs
```

Результат пишется в `dist/index.html`. Текущая итерация и просрочки считаются на дату сборки; её можно задать через `TODAY=2026-10-12`.

## Публикация

При пуше в `main` workflow `.github/workflows/pages.yml` собирает страницу и публикует её в GitHub Pages. В настройках репозитория нужно один раз выбрать Settings → Pages → Source: **GitHub Actions**.
